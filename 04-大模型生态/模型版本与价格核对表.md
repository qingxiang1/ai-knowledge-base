# 模型版本、价格与可用性核对表

> 模型名称、价格、上下文、区域、配额和弃用日期变化很快。本页不复制一个很快失效的“最新排行榜”，而是提供上线前必须执行的核对机制。正文中的旧模型仍可用于理解技术演进，但不得直接作为生产选型结论。

## 一、信息有效期分级

| 信息 | 建议复核频率 | 允许写入长期教程的形式 |
| --- | --- | --- |
| 模型家族与技术演进 | 每季度 | 时间线，并标注历史状态 |
| 模型 ID、API 能力、SDK 用法 | 每月或每次发布前 | 官方链接、核对日期、最小示例 |
| 输入/输出价格、缓存与批处理折扣 | 每次预算/发布前 | 不固化结论；保存本次选型快照 |
| 上下文、输出上限、速率与区域 | 每次环境变更前 | 账户/区域实测 + 官方限制页 |
| 弃用与迁移日期 | 每月 | Owner、影响系统、迁移截止日 |
| 基准与能力排名 | 每季度 | 企业黄金集结果，不用单榜单排名 |

## 四、企业选型最小对照实验

候选模型必须使用同一套黄金数据集、Prompt、工具、检索结果、采样设置、并发条件和区域条件，统一比较：任务成功率、关键错误、P95 延迟、单成功任务成本、人工复核成本和风险事件。

不要只比较单次 Token 单价。更便宜但失败重试多、人工复核重或延迟不稳定的模型，总成本可能更高。

## 五、正文维护规则

1. “最强、唯一选择、当前主流”等结论必须带核对日期或删除。
2. 静态价格表必须标注历史日期，生产预算统一引用本页的新核对记录。
3. 示例模型 ID 若已旧，保留时标注“历史教学示例”，并使用环境变量允许替换。
4. 每篇厂商教程顶部显示易变信息提示和本页链接。
5. 每季度用企业黄金集更新选型，不以厂商发布会直接替换生产模型。
