# 企业级 AI 项目验收清单

> 本清单用于 Project01–Project11，也可作为真实企业项目的评审底稿。低风险项目可以合并门禁，高风险项目不得跳过数据、权限、安全、人工监督和退役检查。

## 一、项目基本信息

```text
项目 / 版本：
业务 Owner / 产品 Owner / 技术 Owner / 风险 Owner：
目标用户与组织：
核心任务：
风险等级：低 / 中 / 高 / 禁止自治
上线区域与租户范围：
计划上线 / 灰度 / 退役日期：
```

## 二、G0 机会与基线

- [ ] 已记录当前人工/规则/旧系统流程、耗时、成本、错误和风险基线。
- [ ] 明确业务结果目标，而不是只写“接入大模型”或“提升智能化”。
- [ ] 比较规则、搜索、RAG、工作流、Copilot、Agent 和人工方案。
- [ ] 明确不适用场景、禁止用途和停止条件。
- [ ] 有业务 Owner、预算、数据 Owner 和最终风险接受人。

## 三、G1 数据与权限

- [ ] 数据源、分类分级、用途、区域、留存和删除规则已登记。
- [ ] 个人、敏感、机密、版权和合同受限数据已完成评审。
- [ ] 检索、缓存、日志、导出和工具调用均继承数据权限。
- [ ] 用户、租户、部门、文档和字段级权限边界已验证。
- [ ] 服务账号使用短期凭证、最小权限和可轮换密钥。
- [ ] 评测集已去标识化，并记录授权与过期复核日期。

## 四、G2 方案与体验

- [ ] PRD 写清能力边界、正常流、异常流、拒答流和人工接管流。
- [ ] 生成内容展示来源、时间、置信提示或不确定性说明（按场景选择）。
- [ ] 高风险动作执行前展示影响范围并要求确认/审批。
- [ ] 写操作支持幂等、撤销、补偿或明确不可逆风险。
- [ ] 用户可以反馈、纠错、申诉和结束自动化流程。
- [ ] 失败时有超时、重试、降级、转人工和可理解的错误信息。

## 五、G3 评测与安全

- [ ] 黄金数据集包含正常、长尾、对抗、权限边界和高风险切片。
- [ ] 评测集、Prompt、策略、模型、代码和工具版本可追溯。
- [ ] 评测覆盖任务成功、忠实性/正确性、引用、拒答、工具和人工接管。
- [ ] Prompt Injection、敏感信息披露、越权、输出处理和无界消耗已测试。
- [ ] 模型裁判经过人工锚点校准；高风险结论保留人工评审。
- [ ] 发布阈值、例外 Owner、例外到期日和回归规则已写入门禁。

## 六、G4 工程与可靠性

- [ ] 明确 P50/P95/P99 延迟、错误率、吞吐、可用性和容量假设。
- [ ] 具备限流、熔断、队列、缓存、超时、重试和降级策略。
- [ ] Agent 有步骤、时间、Token、金额和并发预算，并支持一键终止。
- [ ] 外部模型/工具不可用时能切换、回退或安全停止。
- [ ] Trace 串联用户、租户、版本、模型、检索、工具、成本和结果。
- [ ] 运行手册包含值班人、告警、回滚、RTO/RPO 和灾备演练。

## 七、G5 灰度与业务验收

- [ ] 明确灰度人群、租户、流量比例、对照组和观察窗口。
- [ ] 业务指标、质量指标、成本指标和风险指标均有基线对照。
- [ ] 关键任务成功率没有回退，严重风险事件为 0。
- [ ] 用户采用、修改、重复使用、人工接管和投诉在可接受范围。
- [ ] 单成功任务成本、人工复核成本和边际成本已核算。
- [ ] 业务 Owner、技术 Owner 和风险 Owner 已签署上线结论。

## 八、G6 运营与持续改进

- [ ] 每周审查 Top Bad Case，明确根因、Owner、截止日和回归用例。
- [ ] 每月审查质量漂移、数据新鲜度、SLO、成本和用户反馈。
- [ ] Prompt、策略、模型、知识库和工具变更均有版本与回滚。
- [ ] 每季度重跑供应商、模型、风险和 TCO 评估。
- [ ] 发生 P0/P1 事件时能熔断、保全证据、通知和复盘。

## 九、G7 退役与迁移

- [ ] 已通知用户、业务、运营、数据、安全、法务和供应商。
- [ ] 已停止入口、计划任务、Agent 委派、MCP 工具和外部回调。
- [ ] 已撤销 API Key、OAuth Grant、服务账号、证书和网络权限。
- [ ] 已按政策归档或删除输入、缓存、索引、记忆、日志和临时文件。
- [ ] 供应商已提供数据删除证明或迁移确认。
- [ ] 未完成任务、人工替代流程和用户历史记录已妥善迁移。
- [ ] 已更新 CMDB、资产清单、成本中心、风险登记册和架构图。
